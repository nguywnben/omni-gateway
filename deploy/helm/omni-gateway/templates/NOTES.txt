Omni Gateway has been deployed.

1. Wait for the pod to become Ready:

   kubectl get pods -l app.kubernetes.io/instance={{ .Release.Name }} -n {{ .Release.Namespace }} -w

2. Access the console:

   kubectl port-forward svc/{{ include "omni-gateway.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }} -n {{ .Release.Namespace }}

   Then open http://127.0.0.1:{{ .Values.service.port }}/

   If PANEL_PASSWORD was not provided, the first-run setup token is printed
   in the pod logs:

   kubectl logs deploy/{{ include "omni-gateway.fullname" . }} -n {{ .Release.Namespace }} | grep -i setup

3. OpenAI-compatible endpoint for clients:

   http://{{ include "omni-gateway.fullname" . }}.{{ .Release.Namespace }}.svc:{{ .Values.service.port }}/v1

4. Prometheus metrics are available at /metrics.
   {{- if .Values.secrets.metricsToken }}
   Scrapes must send: Authorization: Bearer <METRICS_TOKEN>
   {{- end }}

NOTE: Omni Gateway 1.x runs as a single replica by design. Do not scale the
Deployment horizontally until distributed state coordination ships.
